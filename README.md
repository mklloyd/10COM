**Pandemic Simulation**
**Computational Thinking**
Skill	Where it appears
Abstraction	People as dots
Modelling	Infection chance, radius
Decomposition	Move, draw, infect, recover
Iteration	Animation loop
Conditionals	Infection, recovery
Variables	infectionChance, recoveryTime

**You can challenge students to:**
1. Add Controls
     Slider for infection chance
     Slider for recovery time
     Population size selector
2. Add Statistics
    Display:
       Number susceptible
       Number infected
       Number recovered
3. Introduce Interventions
     “Lockdown” mode → reduce movement
     “Vaccination” → start some as recovered
     “Masks” → reduce infection chance

These are excellent for:
“evaluating how changing variables affects outcomes”
